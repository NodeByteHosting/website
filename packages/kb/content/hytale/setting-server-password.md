1. Stop your server before making any changes

2. Go to "File Manager"

3. Click on "Config.json"

4. Within your config.json you will see "Password" change this to any password you would like, then save the file.!

![](/kb/hytale/changingpassword/passwordchange.png)

5. Start your server

# Connecting with a server password set

1. Load up Hytale

2. Go to "Servers"

![](/kb/hytale/servershytale.png)

3. Either direct connect or Double Click on the server you added [Knowledge Base found here](https://nodebyte.host)

4. Enter your password here then click "login"

![](/kb/hytale/changingpassword/loginhytale.png)


# Unsetting your password

1. Stop your server before making any changes

2. Go to "File Manager"

3. Click on "Config.json"

4. Remove any text in the password field then save

5. Start your server and you should no longer be asked to sign in.
