Once your server is installed and logged in. Follow this to make yourself an Operator/Admin

1. Stop your server

2. Go to "Startup"

![](/kb/hytale/startup.png)

3. Look for "Allow operators" and toggle it to true

![](/kb/hytale/opadmin/allowop.png)

4. Start your server

5. Load up your server

6. Press Enter and type `/op self` then press enter

You should see a message like this: 

![](/kb/hytale/opadmin/messagehytale.png)

WARNING: YOU MUST CHANGE THIS OPTION BACK TO FALSE OTHER WISE EVERYONE CAN MAKE THEMSELEVES OPERATOR/ADMIN

To do this do the above, but change the "Allow operators" to false

# Adding other players as an Operator/Admin

This is quick and easy to do!

Press enter inside your server and type in `/op add <player name | UUID>`

# Removing other players as an Operator/Admin

This is quick and easy to do!

Press enter inside your server and type in `/op remove <player name | UUID>`
