# Server Owner/s

On the game panel under the startup tab we have provided an easy way to setup your password. 

1. Load up your server
2. Go to the "Start up" tab

![](/kb/palworld/startup.png)

3. Look for "Server Password"

![](/kb/palworld/serverpassword.png)


4. Set a good enough password so that only players you want can join!

5. Reboot the server for it to detect the changes

# Players

On the main menu screen go to "Join Multiplayer Game"

![](/kb/palworld/joinmp.png)

At the bottom you can see a text box to input an IP and to the left you will see a check box to select to enter a password (If the server requires one)

![](/kb/palworld/joinmppass.png)

Enter the password provided by your server owner/s or admin/s - There is an option to save the password (We have no control over this). 

![](/kb/palworld/joinmppassok.png)

Click "OK" then you will start connecting to the server!
