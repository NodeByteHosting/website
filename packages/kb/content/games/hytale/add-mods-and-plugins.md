At this time there is only a fair few mods that will require additional setting up, please check their documentations for help!

We recommend getting mods from [curseforge](https://www.curseforge.com/hytale)

# Adding plugins to your server

1. Stop your server

2. Go to "File Manager"

3. Go to a folder called "mods"

4. Drag the .jar into the folder 

5. Once the .jar file is uploaded start your server backup!


# Adding Mods to your client

1. On the "Hytale Launcher" click the gear icon in the top left corner

![](/kb/hytale/gear.png)

2. Click on "Open directory"

![](/kb/hytale/directory.png)

3. Go to "UserData/Mods"

4. Drag the .jar file into this location then start up hytale!
